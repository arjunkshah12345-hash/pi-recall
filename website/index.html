What changes

Every sentence becomes future context.

Pi Recall listens for “Hey Pi,” records the next utterance, stores the exact transcript in the local Supermemory process, then retrieves relevant profile and memory context before answering out loud.

localhost:6767

Stored utterance

“The garage sensor has been flaky since the storm. Check the battery first.”

Later query What should I try before replacing it?

Response

“Check the garage sensor battery first.”

The answer is short because it is spoken. The context comes from Supermemory Local, not a hosted memory API.
